# Samuel Omojo Ronald — Portfolio

Personal cybersecurity & engineering portfolio built with **HTML5, CSS3 (custom properties + CSS Grid/Flexbox), and vanilla JavaScript**.

## Stack

- HTML5 (semantic, accessible)
- CSS3 — custom properties, Grid, Flexbox, scroll-reveal, CRT scanlines
- Vanilla JavaScript — typewriter effect, Intersection Observer animations, active nav tracking
- Google Fonts: JetBrains Mono + Inter
- Zero dependencies, zero build step
